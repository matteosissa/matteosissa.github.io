MiLa es una aplicación web diseñada para una asociación de voluntariado que lucha contra la violencia y el abuso hacia las mujeres. Fue desarrollada utilizando Nuxt, un framework de Javascript construido sobre VueJs.

Se puede visitar la página al siguiente enlace: [MiLa Página Web](https://mila-website-frontend.vercel.app/).

### 🎯 Objetivo del Proyecto

El objetivo de este proyecto era crear una **aplicación web** para alojar toda la información relevante para una **asociación de voluntariado** que ayuda a mujeres víctimas de **violencia** o **abuso**. El enfoque principal estaba en el **frontend** y el diseño de la interfaz gráfica, para ofrecer la mejor **experiencia de usuario**.

### 🏗️ Arquitectura del Sitio Web

El [informe de diseño](/uploads/mila-website/design-report.pdf) detalla todos los aspectos de diseño del sitio web. El equipo para este proyecto incluía un **diseñador** que ayudó a los desarrolladores con gráficos, imágenes y diseño. El diseño se completó primero completamente en **Figma** y luego se reprodujo en HTML.

Desde el punto de vista arquitectónico, el sitio web se construyó como una **arquitectura de tres capas**. El frontend fue diseñado con **NuxtJS** e interactuaba con una aplicación backend escrita con **NodeJs**, que a su vez aprovechaba una base de datos alojada en **Supabase**. También había un **chatbot** integrado en el sitio web que estaba personalizado para ofrecer **apoyo psicológico** a todas las mujeres que visitaran la página web. El [informe tecnológico](/uploads/mila-website/technology-report.pdf) ilustra todos estos aspectos con mayor detalle.

### 💯 Resultados y Habilidades Adquiridas

El proyecto MiLa fue fundamental porque me ayudó a entender cómo trabajar en un **proyecto multidisciplinario**. De hecho, el equipo no estaba compuesto solo por desarrolladores, sino que también había un diseñador. Por lo tanto, fue necesario aprender a colaborar con personas que tienen **antecedentes educativos completamente diferentes** y roles diferentes en el proyecto. También me permitió dominar las habilidades necesarias para construir **aplicaciones web frontend**. No se trataba solo de aprender nuevas tecnologías frontend como NuxtJs, sino también de entender cómo estructurar la información en una página web de manera **efectiva** y visualizar el contenido de manera agradable para obtener la mejor **experiencia de usuario**.
