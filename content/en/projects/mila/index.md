MiLa is a web application designed for a volunteering association fighting against women's violence and abuse. It was developed using Nuxt, a Javascript framework built on top of VueJs.

It is possible to visit the website at the following link: [MiLa Website](https://mila-website-frontend.vercel.app/).

### 🎯 Project Goal

The goal for this project was to create a **web application** to host all the relevant information for a **volunteering association** helping women victims of **violence** or **abuse**. The main focus was on the **frontend** and design of the graphical interface, to offer the best **user experience**.

### 🏗️ Website Architecture

The [design report](/uploads/mila-website/design-report.pdf) details all design aspects of the website. The team for this project included a **designer** who helped developers with graphics, images and layouts. The design was first fully realized in **Figma** and then reproduced in HTML.

From an architectural point of view, the website was built as a **three-tier architecture**. The frontend was designed with **NuxtJS** and it interacted with a backend application written with **NodeJs**, which in turn would leverage a database hosted on **Supabase**. There was also a **chatbot** integrated in the website that was custom-trained to **psychologically support** all women landing on the webpage. The [technology report](/uploads/mila-website/technology-report.pdf) illustrates all these aspects with more detail. 


### 💯 Results and Skills Acquired

The MiLa project was pivotal because it helped me understand how to work in a **multidisciplinary project**. Indeed, the team did not consist solely of developers, but there was also a designer. Therefore, it was necessary to learn how to collaborate with people who have completely **different educational backgrounds** and different roles in the project. It also made me master the skills that are necessary to build **frontend web applications**. It was not just about learning new frontend technologies like NuxtJs, but also understanding how to structure the information on a webpage **effectively** and display the content in a nice-looking way to achieve the best **user experience**.
